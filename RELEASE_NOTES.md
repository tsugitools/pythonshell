# Release notes

Short copy for app-store “What’s new” fields. Newest first.

## Unreleased

About now credits Python for Everybody (www.py4e.com). On the website use the About button; in the desktop app use Help → About PythonShell.

## v0.9.3

Store identity matches the Microsoft Partner Center listing (Dr. Chuck / PythonShell). Same playground as before: editor, shell, and in-app Python.

## v0.9.2

Windows packaging now meets Store requirements (Windows 10 1809 or later, publisher display name Dr. Chuck). The editor, shell, and Python runtime are unchanged.

## v0.9.1

In Chrome and Edge, downloading a workspace file can replace an existing file instead of creating “file (2)”. Windows tagged builds also include an MSIX package for the Microsoft Store.

## v0.9.0

First desktop release of PythonShell: a free Python playground from Python for Everybody. Edit files, press Run, and use a small Linux-like shell. Python runs on your computer; no account required.
